# Gamma-Gamma Absorption Validation

This validation consumes the opacity tables generated by the production
Fortran routine `opac_gg.f90`. It does not duplicate the gamma-gamma opacity
integral or participate in the normal build.

## Workflow

From the project root, first generate `output/opac_gg1.dat` and
`output/opac_gg2.dat` with the production configuration using `absgg=on`.
Activate an environment containing the documented Python dependencies and run:

```text
python3 validation/gamma-gamma_absorption/plot_transmission.py
```

The script writes map data files and `gamma-gamma_transmission.pdf` under
`results/`.

The script samples the production tables for the current reference geometry
at observer angles of 1 and 60 degrees. It produces a three-row by two-column
PDF figure for 20 GeV, 100 GeV, and 1 TeV. Each panel shows the combined
transmission through both stellar photon fields, with contours at 90%, 30%, and 10%
absorption.

The map sampler reproduces the table lookup and radial scaling used by the
current gamma-gamma consumers:

```text
tau_star = (R_star / distance_to_star) * tau_table(energy, angle)
transmission = exp(-(tau_star1 + tau_star2))
```

The current validation geometry is recorded in the script: `distance=2.4 kpc`,
projected reference separation `47 mas`, reference angle `85 degrees`, and
`Rstar1=Rstar2=6 R_sun`. Change these values deliberately when validating a
different system.
